# 鄉區道標誌產生器
鑒於多數縣市的鄉區道長期在網站上無提供該標誌的向量檔，且手動製作檔案的效率過低，爰此本專案以Python開發鄉區道標誌「指4」產生器，以提升產製速度並自動化。

## 說明
* 標誌規格遵循[《道路交通標誌標線號誌設置規則》第90條第3項之「指4」規定](https://law.moj.gov.tw/LawClass/LawGetFile.ashx?FileId=0000372594&lan=C)。
* 目前[主線](https://commons.wikimedia.org/wiki/Category:Diagrams_of_township_and_district_road_signs_of_Taiwan)及[專用公路](https://commons.wikimedia.org/wiki/Category:Diagrams_of_exclusive_highway_signs_of_Taiwan)部分皆已全數上傳至維基共享資源，提供公眾使用。支線部分仍需要欽點有哪些後再陸續上傳。
